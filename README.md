# ✈️ Flight Price Analysis – EDA & Feature Engineering (Python)

## 📌 Project Overview
This project focuses on **Exploratory Data Analysis (EDA)** and **Feature Engineering** for a flight price dataset.  
The goal is to understand the key factors affecting flight prices and prepare clean, meaningful features for future machine learning models.

This project demonstrates my ability to:
- Analyze real-world datasets
- Handle missing and inconsistent data
- Extract useful features from date/time variables
- Perform data visualization and insights generation

---
## 📂 Data
- **Raw data:** Original flight price dataset
- **Processed data:** Feature-engineered dataset ready for modeling

## 📊 Dataset Description
The dataset contains flight-related information such as:
- Airline
- Source and destination
- Date of journey
- Departure and arrival time
- Duration
- Number of stops
- Ticket price

---

## 🔍 Exploratory Data Analysis (EDA)
Key EDA steps performed:
- Checked data shape, data types, and missing values
- Analyzed price distribution and outliers
- Explored relationships between price and:
  - Airline
  - Number of stops
  - Journey date
  - Duration
---

## 🛠 Feature Engineering
Important feature engineering steps:
- Extracted **Day, Month** from journey date
- Converted **Duration** into total minutes
- Processed **Departure and Arrival time** into hour and minute features
- Encoded categorical variables using appropriate techniques
- Removed redundant and non-informative columns

Final dataset is ready for **machine learning modeling**.

---

## 📈 Key Insights
- Flights with more stops generally have lower prices
- Certain airlines consistently show higher average prices
- Prices vary significantly based on journey month and timing
